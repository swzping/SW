# Codex 如何接入 MCP

标签：#codex #mcp #agent #概念

## 核心内容

Codex 可以通过 MCP server 接入外部工具和数据。对本地个人知识库来说，MCP server 可以作为 Codex 与 Markdown 知识库之间的工具层：Codex 负责理解和决策，MCP server 负责安全读取和受控写入文件。

## 我的判断

Codex 接入 MCP 的价值不在“多一个插件”，而在于把知识库整理流程变成稳定工具。第一版应该只提供少量明确工具，例如读取工作台、读取整理建议、创建原子知识和更新主题地图。写操作必须保留确认边界，避免知识库被自动内容污染。
