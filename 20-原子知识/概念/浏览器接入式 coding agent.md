# 浏览器接入式 coding agent

标签：#agent #coding-agent #browser-use #frontend #evals #概念

## 核心内容

浏览器接入式 coding agent 指编码 Agent 不只修改代码和运行测试，还能打开真实页面、观察 DOM/截图/控制台/网络请求，并基于页面反馈继续修复。它把前端开发从“代码层验证”推进到“页面级闭环验证”。

## 我的判断

这条线对前端开发者很重要。未来高质量 coding agent 的差异，不只是能不能写组件，而是能不能在真实浏览器里验证布局、交互、错误、响应式和视觉结果。它也是 `Frontend QA MCP` 的关键依据：让 Agent 通过浏览器观察结果，而不是只凭代码推断结果。

## 关键组成

- 浏览器控制：打开页面、点击、输入、跳转、滚动。
- 页面观察：截图、DOM、可访问性树、console、network。
- 验证 loop：改代码 -> 跑页面 -> 观察问题 -> 再修复。
- 前端质量标准：响应式、文字溢出、布局错位、交互状态、加载错误。
- 人类确认：视觉判断和产品取舍仍应由人最终确认。
