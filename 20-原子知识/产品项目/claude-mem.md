# claude-mem

标签：#memory #agent #coding-agent #产品 #待验证

## 核心内容

claude-mem 是一个值得跟踪的 coding agent 记忆层项目方向：它试图让 Claude Code 或类似 agent 在跨会话工作中保留项目上下文、经验摘要和可复用记忆。

## 我的判断

它对我的价值不只是“同步记忆”本身，而是启发这个知识库如何做长期记忆：哪些内容应该自动沉淀，哪些内容应该人工确认，哪些记忆会污染后续判断。知识库的自生长流程可以借鉴这类项目，但不能无脑自动保存所有内容。
