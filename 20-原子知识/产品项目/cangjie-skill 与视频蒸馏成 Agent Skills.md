# cangjie-skill 与视频蒸馏成 Agent Skills

标签：#skill #agent #context-engineering #knowledge-management #产品项目

## 核心内容

`cangjie-skill` 是一个开源项目，目标是把书、长视频、播客、访谈等高价值内容蒸馏成可调用的 Agent Skills，而不是只生成摘要或读后感。它强调的不是“压缩内容”，而是把原内容中的方法论拆成可触发、可组合、可测试、可安装到 Agent 里的 skill 包。

## 我的判断

这个项目对我最有价值的地方，不是它服务哪一本书，而是它提供了一个非常贴近知识库整理的方向样本：收藏过的长内容，不一定直接变成原子知识，也可以先被蒸馏成“可执行方法单元”。这和我现在要做的“社媒收藏 -> 筛选 -> 原子知识 / 主题地图 / 可复用能力”是同一条线。

它也提醒我，社媒内容真正值得升级的，不是短视频本身，而是其中能否抽出可验证、可迁移、可反复调用的方法论。如果后续要做“抖音收藏到知识库”的自动化，这类 skill 化方法比普通摘要更有长期价值。

## 它解决什么问题

- 收藏了很多长内容，但知识停留在“看过/存过”，无法在真实任务中调用。
- 普通摘要和笔记只能压缩内容，不能告诉 Agent 什么时候该用什么方法。
- 高价值内容需要严格筛选，不能照单全收进入知识库。

## 为什么值得关注

- 它把 `skill` 从提示模板推进到“可从外部内容蒸馏出来的结构化能力”。
- 它天然连接 `context engineering`、`知识库整理`、`Agent 记忆外部化`。
- 它给“社媒收藏如何升级”为可复用能力提供了更具体的方法方向。
