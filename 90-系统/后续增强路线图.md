# 后续增强路线图

这个文件用于提醒未来如何增强知识库。先不要一次性全部自动化，等知识库自然积累出稳定流程后再升级。

## 阶段 0：手动自生长

当前阶段目标：让目录、模板、标签和主题地图先跑起来。

完成标准：

- 每天至少有一个输入进入 `10-输入流/`。
- 每周至少新增 5 条原子知识。
- 每周至少更新 1 个主题地图。
- 每周至少写 1 篇综合输出。

暂时不要做的事：

- 不急着上向量数据库。
- 不急着自动抓取所有网页。
- 不急着让 LLM 全自动写判断。

## 阶段 1：半自动整理

触发条件：`10-输入流/` 每周超过 10 篇材料，手动整理开始费力。

可增强项：

- 写一个脚本扫描 `10-输入流/`，提取候选关键词、链接和标签。
- 让 LLM 按模板生成原子笔记草稿，但保留人工确认。
- 自动检查没有来源、没有标签、没有下一步问题的笔记。
- 自动生成“本周新增笔记清单”。
- 使用 [[规则/自动整理流程|自动整理流程]]：早上生成输入流整理建议，晚上主动推进工作台待拆解想法。

建议产物：

- `90-系统/脚本/scan_inputs.py`
- `90-系统/脚本/check_notes.py`
- `40-综合输出/周报/YYYY-WW.md`

## 阶段 2：主题地图自动维护

触发条件：`20-原子知识/` 超过 100 篇，主题之间开始难以手动追踪。

可增强项：

- 根据标签和双链统计高频主题。
- 自动提示哪些主题应该新建地图。
- 自动列出某个主题下最近新增的原子知识。
- 自动发现孤立笔记，也就是没有主题链接的笔记。

建议规则：

- 同一标签超过 3 篇原子笔记，建议创建主题地图。
- 同一主题地图超过 20 条链接，建议拆子主题。
- 30 天未被链接的原子笔记，进入清理列表。

## 阶段 3：RAG 与问答层

触发条件：知识库超过 300 篇笔记，且经常需要问“以前有没有记过”。

可增强项：

- 建立本地全文索引或向量索引。
- 支持按主题、时间、标签和来源混合检索。
- 给每次回答附上引用笔记路径。
- 把问答结果反写成新的研究备忘录。

推荐原则：

- 先做全文检索，再做向量检索。
- 先保证引用准确，再追求回答流畅。
- RAG 回答只作为草稿，不直接替代综合判断。

## 阶段 4：自动情报流水线

触发条件：你希望它每天主动产出 AI/LLM 情报。

可增强项：

- 定时抓取 GitHub Trending、Hacker News、arXiv、厂商博客和模型榜单。
- 自动生成 AI 热词日报。
- 从日报中提取候选原子知识。
- 每周自动生成趋势变化表。

建议流水线：

1. 抓取来源。
2. 去重和清洗。
3. 生成日报。
4. 生成原子笔记草稿。
5. 更新主题地图。
6. 生成人工复核清单。

## 阶段 5：个人研究助手

触发条件：知识库已经能稳定回答“我最近怎么看某个主题”。

可增强项：

- 针对每个主题维护长期观点版本。
- 记录判断变化历史。
- 生成研究问题队列。
- 根据你的兴趣主动推荐下一篇论文、项目或产品发布。

最终目标：

让知识库不仅回答“我收集过什么”，还回答“我为什么这么判断，以及这个判断下一步应该如何验证”。

## 增强优先级

1. 先补模板和规则。
2. 再做质量检查脚本。
3. 再做主题地图自动维护。
4. 最后再做 RAG 和自动抓取。

不要跳过前两步。没有稳定笔记结构的 RAG，只会把混乱放大。
