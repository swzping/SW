# LLM Knowledge Base Design

## Goal

Create an AI/LLM industry-intelligence knowledge base that can grow from daily inputs into reusable concepts, topic maps, and periodic research judgments.

## Scope

The initial version is a Markdown and Obsidian friendly folder system. It includes entry pages, self-growth rules, tag conventions, templates, topic maps, and an enhancement roadmap.

## Architecture

The knowledge base uses five layers:

1. Input stream for raw and lightly processed material.
2. Atomic knowledge for reusable single-idea notes.
3. Topic maps for emergent structure.
4. Synthesized outputs for weekly reports and research memos.
5. System rules and templates for governance.

## Growth Rules

- Inputs must be filtered before becoming knowledge.
- Atomic notes must contain one idea, one judgment, source links, related themes, and a next question.
- Topic maps are created when a concept appears in at least three atomic notes.
- Weekly synthesis turns facts into judgments.
- Future automation should start with quality checks before RAG or full ingestion.
