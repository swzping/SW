# AI/LLM 自生长知识库

这个知识库用于持续追踪 AI、LLM、Agent、RAG、模型基础设施和相关产业变化。

它不是资料仓库，而是一个会生长的认知系统：每天接收输入，拆成原子知识，挂到主题地图，定期综合成判断，再用新问题驱动下一轮收集。

## 快速入口

- [[今日工作台]]：每天从这里开始。
- [[../90-系统/规则/自生长规则|自生长规则]]：决定一条信息如何进入知识库。
- [[../90-系统/标签体系|标签体系]]：统一标签，避免越记越乱。
- [[../90-系统/后续增强路线图|后续增强路线图]]：以后想自动化、接 RAG、做日报周报时看这里。

## 目录说明

| 目录 | 用途 |
| --- | --- |
| `10-输入流/` | 未加工或轻加工的信息，包括日报、网页摘录、论文摘录、产品发布记录。 |
| `20-原子知识/` | 一条笔记只表达一个概念、判断、人物、组织、产品、论文或技术点。 |
| `30-主题地图/` | 把多个原子知识组织成可导航的主题页。 |
| `40-综合输出/` | 周报、趋势判断、研究备忘录等二次加工成果。 |
| `90-系统/` | 规则、模板、标签、增强路线图。 |

## 每日最小流程

1. 把当天资料放进 `10-输入流/`。
2. 从输入里挑 3-5 条值得长期保留的信息。
3. 拆成 `20-原子知识/` 里的原子笔记。
4. 把原子笔记链接到 `30-主题地图/`。
5. 在 [[今日工作台]] 里留下一个下一步问题。

## 生长原则

- 输入不是知识，经过筛选、解释和链接后才是知识。
- 主题不是预先设计完的，而是从反复出现的原子知识里长出来的。
- 每周至少做一次综合输出，把事实升级成判断。
- 每条重要笔记都要留下来源、判断和下一步问题。
