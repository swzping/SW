# LLM

标签：#llm #主题地图

## 这个主题是什么

大语言模型本身及其能力边界，包括模型架构、推理能力、工具调用、长上下文、多模态、成本和评测。

## 为什么现在重要

LLM 是 Agent、RAG、AI 产品和 AI 基础设施的底层变量。模型能力、价格和上下文机制的变化，会直接改变上层应用的形态。

## 关键分支

- 模型能力与新模型发布
- 推理成本与效率
- 模型路由与 AI gateway
- AI 基础设施与算力出海
- 长上下文与记忆
- 评测与可观测性
- 多模态能力

## 当前判断

LLM 竞争正在从单点能力转向“模型 + 工具 + 上下文 + 评测 + 成本控制”的系统竞争。随着模型数量和 provider 增多，模型选择会逐渐从代码里的固定配置变成外部化的路由策略。

算力出海与 Token 出海说明 LLM 的竞争还会延伸到区域节点、推理成本、网络延迟、数据合规和全球交付能力。对个人而言，这更适合作为基础设施背景变量，而不是短期直接切入点。

## 下一步追踪

- 新模型是否真正提升长任务完成率。
- 成本下降是否改变 Agent 的使用频率。
- AI gateway 是否会成为多模型应用的默认基础设施。
- 算力出海是否会改变小团队使用模型 API 的成本和可用性。
