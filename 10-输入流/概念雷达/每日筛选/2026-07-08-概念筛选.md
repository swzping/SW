# 2026-07-08 概念筛选

日期：2026-07-08
对应日报：[[../../日报/AI圈新闻-2026-07-08|AI圈新闻 - 2026-07-08]]

## 先给结论

今天最该筛出来的，不是“又多了几个新 agent 框架”，而是下面四条已经被官方平台和高增仓库同时强化的长期能力方向：

1. `workflow layer > model catalog` 已经进入平台显性战略。
2. `agent observability / session visibility` 正在从第三方工具走向平台内建能力。
3. `Skill` 正在从 coding 扩到 design，进一步证明它是组织层资产，不只是提示模板。
4. `文档 / runtime / trace` 三条线开始收敛成同一件事：让 agent 的上下文和执行都更可读、可控、可复盘。

## 今天值得关注的概念

### 1. workflow layer > model catalog

- 来自信号：
  - GitHub `GitHub Models` 将于 `2026-07-30` 完全退场
  - GitHub 同周把 `Copilot agent session streaming` 放入 public preview
- 为什么值得关注：
  - 这说明平台竞争点继续从“给多少模型”转向“如何让 agent 真正进入团队工作流”。
- 建议动作：
  - 作为长期判断挂在 `AI 基础设施` 与 `coding agent 平台` 观察下。
- 判断：
  - 长期能力方向，重要性 `A`。

### 2. agent observability / session visibility

- 来自信号：
  - Copilot agent session streaming
  - `shepherd` 的 trace / replay / revert runtime
  - 长期基准项目 `langfuse`
- 为什么值得关注：
  - 说明 `看见 agent 做了什么` 已经从“高级玩法”变成企业级必要能力。
- 建议动作：
  - 作为 `Observability / Tracing` 的新样本继续跟踪，不急着单独建很多仓库卡片。
- 判断：
  - 长期能力方向，重要性 `A`。

### 3. design agent skills

- 来自信号：
  - Figma `Got skills?`
  - Figma `custom tools + greater context + skills`
  - Figma Help `Custom skills for the Figma agent and Figma Make`
- 为什么值得关注：
  - 这说明 `Skill` 已经不再局限于 coding agent，而是在设计协作、设计到代码和团队方法沉淀中成立。
- 建议动作：
  - 在 `Agent Skill` 的长期判断下补一句：它已经跨 coding / design workflow 形成通用组织层。
- 判断：
  - 长期能力方向，重要性 `A-`。

### 4. 项目文档资产化

- 来自信号：
  - `openwiki`
  - `security-audit-skill`
  - `gzh-design-skill`
- 为什么值得关注：
  - 一端是仓库文档，一端是安全流程与内容排版流程；它们共同说明“把人类方法写成 agent 可执行资产”正在扩散。
- 建议动作：
  - 适合拆一条轻量原子知识候选，但不把每个热仓库都升级到长期追踪。
- 判断：
  - 长期能力方向，重要性 `B+`。

### 5. reversible runtime / trace substrate

- 来自信号：
  - `shepherd`
  - `langgraph`
  - 持续存在的 eval / tracing 工程需求
- 为什么值得关注：
  - 这条线可能是下一阶段 `meta-agent`、`supervisor`、`回放调试` 的底层设施。
- 建议动作：
  - 先保留在 `Agent` 与 `模型评测` 交叉观察，不急于升格为独立主题。
- 判断：
  - 长期能力方向，重要性 `B+`。
