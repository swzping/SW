## 今天值得关注的概念

### 1. `Agent observability / replay`

- 为什么值得关注：今天最有辨识度的新样本不是单个官方公告，而是 `skill-recorder`、`agentacct`、`numbat` 这组仓库同时在补 `record / replay / cost / policy / security`。
- 今天的判断：`observability` 已经不只是 tracing 后台，而是在往 `用户可见、团队可审、可取证、可复盘` 的工作台能力走。
- 建议动作：先升级为高优先级概念候选，适合拆成原子知识，但今天不急着把单个仓库升为长期对象。

### 2. `Skills + MCP + code review`

- 为什么值得关注：GitHub Copilot 已经把这条线推到 GA，Codex review rules 又给了另一侧证据。
- 今天的判断：这条线已经足够稳定，不应再按“单平台功能”看，而应按 `review-time context injection` 看。
- 建议动作：继续作为长期判断保留，适合优先拆成正式原子知识。

### 3. `Price-performance frontier`

- 为什么值得关注：OpenAI 明确把 GPT-5.6 的价值翻译成 `价格 / 性能 / workflow`，这会影响默认模型切换和路由策略。
- 今天的判断：这条线仍然比“某模型更强”更重要，因为它解释真实采用决策。
- 建议动作：继续作为长期主线保留，适合进入 `AI 基础设施` 或模型判断框架。

### 4. `Design-to-code workspace`

- 为什么值得关注：Vercel Agent、Cursor Router、Figma Make 的近期动作共同说明，重点已从首稿生成转向 `annotation / handoff / telemetry / local code / approvals`。
- 今天的判断：这会直接影响你如何看待前端 agent、设计 agent 和 AI app builder 的边界。
- 建议动作：保留在长期方向里，不急着新增太多单产品笔记。

### 5. `MCP engineering phase`

- 为什么值得关注：MCP RC 与 GitHub next-spec support 的组合，仍然是协议进入工程期的最强证据。
- 今天的判断：这条线今天没有出现颠覆性新增，但持续有效，后续更该比较 `host / auth / tasks / apps / migration cost`。
- 建议动作：继续作为长期能力方向保留。
