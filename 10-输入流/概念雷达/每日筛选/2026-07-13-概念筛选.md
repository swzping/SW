## 今日先看什么

今天不需要追“又多了几个高 star 仓库”。更值得筛出来的是四条连续出现、且正在改变工程实践的长期变量：

1. `session visibility / tool-call visibility`
2. `context compression`
3. `browser-native / MCP tooling`
4. `AI app builder 的治理层`

## 今天值得关注的概念

### 1. `session visibility / tool-call visibility`

- 为什么值得关注：GitHub Copilot 持续把 session streaming、tool calls、session events 放进主界面。
- 今天的判断：`observability` 正在从后台 tracing 工具变成默认交互层。这会直接影响你如何审查、接管和信任 Agent。
- 建议动作：维持长期主线；后续优先沉淀成原子知识。

### 2. `context compression`

- 为什么值得关注：Anthropic 的 context engineering 方法论与 `headroom` 这类工具样本，开始把“压缩上下文”从技巧推成独立工程层。
- 今天的判断：这不是普通 token 优化。它关系到长任务稳定性、RAG 成本、工具输出可读性和多轮 loop 的可持续性。
- 建议动作：更新长期概念雷达，把它挂到 `Context Engineering` 主线下。

### 3. `browser-native / MCP tooling`

- 为什么值得关注：`Safari MCP server`、`browser-use`、`playwright-mcp` 这条线持续增强。
- 今天的判断：前端调试、页面验证和浏览器自动化正在从“外部脚本”转成“Agent 可直接操作的工作环境”。
- 建议动作：维持长期主线；不把单个仓库自动升入长期雷达。

### 4. `AI app builder 的治理层`

- 为什么值得关注：`AI SDK 7`、`v0`、`Figma Make`、`Lovable` 这类产品越来越强调 skills、runtime context、权限和本地代码协作。
- 今天的判断：竞争点正在从“能不能生成页面”转向“能不能进入真实团队流程”。
- 建议动作：继续挂在 `主流模型平台与工具产品雷达`，暂不拆单独主题。

### 5. `skill 资产化`

- 为什么值得关注：高 star skill 仓库还在增长，OpenAI / Claude / Figma 官方线也持续强化它。
- 今天的判断：长期方向成立，但“技能合集仓库”本身常常只是噪音外壳；真正值得长期跟踪的是 `skill + evals + versioning + memory` 的组织层。
- 建议动作：继续长期跟踪，但不要把每个 skills 仓库都当作长期对象。
