## 今日判断

今天最关键的变化不是“又有几个新工具”，而是平台层和开源层都在把 agent 能力收敛到四个工程面：

1. `组织层`
   - skills
   - review policy
   - team method assets

2. `工作台层`
   - ChatGPT + Codex
   - browser-based work
   - long-running tasks

3. `接口层`
   - v0 API
   - local code
   - MCP / browser tools

4. `观测层`
   - local-first dashboards
   - loop evidence
   - evals / token / cost visibility

这说明 AI/Agent 的主线继续从“模型能不能生成”转向“系统能不能组织、调用、审查和观测”。
