## 今天值得关注的概念

### 1. `统一 Agent 工作台`

- 为什么值得关注：`ChatGPT Work` 把 ChatGPT desktop、Codex、connectors、record mode、deep research 和 app / site 生成能力往同一入口收。
- 今天的判断：这不是普通产品打包，而是 `coding agent + 知识工作 + app builder` 开始共用一个工作介质。
- 建议动作：挂到 `主流模型平台与工具产品雷达`，并更新 `Codex` 的当前判断。

### 2. `workflow layer > model catalog`

- 为什么值得关注：GitHub 明确 `GitHub Models` 将于 `2026-07-30` 关闭，同时 GitHub Copilot 和 Vercel AI SDK 都在强化 workflow、trace、runtime context、skills 和治理层。
- 今天的判断：平台真正的长期价值越来越不在“挂了多少模型”，而在“能否把任务稳定执行出来并可审查、可接管、可授权”。
- 建议动作：维持长期主线，不单独新增产品条目。

### 3. `session visibility / tool-call visibility`

- 为什么值得关注：GitHub 官方 changelog 连续几天把 `session streaming`、`tool calls`、`session events` 往主界面层推进。
- 今天的判断：`observability` 不再只是后台 trace，而是 Agent 默认交互方式的一部分。
- 建议动作：继续作为长期方向；今天不需要再更新长期雷达正文。

### 4. `skill + governance + context engineering`

- 为什么值得关注：OpenAI、Anthropic、Vercel、Figma 各自从不同角度强化 `skill`、`context engineering`、`runtime context` 和授权治理。
- 今天的判断：这几条线正在合并成 Agent 工程基础层，不能再拆开理解。
- 建议动作：今天不建新主题地图，但可作为后续原子知识主线。

### 5. `跨平台 skill 分发`

- 为什么值得关注：`agentpack` 这类项目开始尝试“一份 skill，多平台分发”，而多个高 star skill 仓库继续扩张。
- 今天的判断：这说明 `skill` 正在从平台内功能，向跨平台可迁移资产发展；但当前仓库热度仍高于真正的稳定标准。
- 建议动作：先观察，不升级为长期独立主线。
