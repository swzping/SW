## 今天值得关注的概念

### 1. `MCP 工作流化`

- 为什么值得关注：`MCP Apps` 与 `Enterprise-Managed Authorization` 已经把关注点从“如何接更多工具”推向“如何安全地接入真实工作环境”。
- 今天的判断：MCP 的下一阶段重点不是 server 数量，而是 `授权、UI、审批、边界、接管`。
- 建议动作：维持长期主线，今天建议补一条长期判断更新。

### 2. `Skill 仓库化 / 方法资产化`

- 为什么值得关注：OpenAI、Anthropic、Figma 继续给出官方证据，GitHub Trending 又出现 `mattpocock/skills`、`ibelick/ui-skills` 这类显式 skill 仓库。
- 今天的判断：`Skill` 已经不只是平台内功能，而是可传播、可协作、可版本化的方法资产。
- 建议动作：维持长期主线，建议补到长期概念雷达，不急着再建新主题。

### 3. `Cloud Agent 工作台化`

- 为什么值得关注：GitHub Copilot 文档把 `cloud agent`、`MCP servers`、`custom agents`、`memory`、`task results` 收在同一层。
- 今天的判断：主流 coding agent 正在从“会改代码”升级成“可委派、可连接、可回看、可治理”的异步执行工作台。
- 建议动作：建议保留为长期判断，并考虑后续拆成原子知识。

### 4. `browser-native MCP`

- 为什么值得关注：`Safari MCP server` 和 `playwright-mcp` 都在说明浏览器已经从测试对象转成 Agent 的常驻工作介质。
- 今天的判断：对前端研发来说，这条线比泛化 computer use 更直接、更可能先形成稳定默认工作流。
- 建议动作：建议补到 `Agent` 或 `AI 基础设施` 主题地图，但今天不单独新建长期概念条目。
