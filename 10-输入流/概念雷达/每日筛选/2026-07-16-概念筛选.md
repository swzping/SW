## 今天值得关注的概念

### 1. `Cloud Agent + MCP + 指标面板`

- 为什么值得关注：GitHub Copilot Cloud Agent 文档已经把 `委派 issue / PR`、`默认 MCP server`、`任务指标` 写成一套完整工作流。
- 今天的判断：主流 coding agent 正在从“会改代码”升级成“可委派、可连接、可追踪、可回看”的云端执行层。
- 建议动作：建议补到长期产品雷达，不单独新建概念主题。

### 2. `Skill 资产化继续跨平台`

- 为什么值得关注：OpenAI、Anthropic、Figma 与 GitHub Trending 的多个 skill 仓库继续形成连续证据链。
- 今天的判断：`Skill` 已经稳定跨过 coding、design、growth 和审美校正等场景，不再只是工程提示模板。
- 建议动作：维持长期主线，继续优先考虑拆成可复用方法资产的原子知识。

### 3. `模型偏好进入 workflow layer`

- 为什么值得关注：OpenAI 把 `GPT-5.6` 写成 Microsoft 365 Copilot 的 preferred model。
- 今天的判断：平台正在把模型选择推到默认执行层，模型目录越来越像基础设施。
- 建议动作：作为长期判断继续保留，今天不单独建新主题地图。

### 4. `browser-native MCP`

- 为什么值得关注：`Safari MCP server` 与 GitHub Cloud Agent 默认支持 `Playwright MCP server` 共同说明浏览器正在原生接入 Agent 工作流。
- 今天的判断：对前端研发来说，浏览器正在从测试对象转成常驻工具介质。
- 建议动作：建议补到 `Agent` 或 `AI 基础设施` 主题地图，但先不新建长期概念条目。

### 5. `Agent 安全防线工程化`

- 为什么值得关注：`destructive_command_guard` 这类项目在 Trending 上升，说明社区开始把“阻止 agent 干坏事”做成独立工具层。
- 今天的判断：权限、防误删、防危险命令，正在从提示约束变成外部工程控制层。
- 建议动作：先当样本观察，不直接升级为长期主线。
