## 今天值得关注的概念

### 1. `Workflow layer > model catalog`

- 为什么值得关注：`GitHub Models retired` 把这条判断补成了更硬的证据，叠加 `Cursor Router`、`Vercel Agent / AI Gateway`，平台价值越来越来自 `runtime / routing / governance / observability`。
- 今天的判断：这条线已经不只是 AI gateway 公司的叙事，而是在主流 agent 平台持续收敛。
- 建议动作：继续保留为高优先级长期判断；如果要推进，适合拆成原子知识而不是只停留在日报里。

### 2. `Review policy + automation boundary`

- 为什么值得关注：`Codex review rules`、`GitHub Issues automation controls`、`GitHub MCP Server next spec` 连续说明，coding agent 的竞争点正在进入治理层。
- 今天的判断：这条线已经是稳定主线，不再只是某天的单条新闻。
- 建议动作：继续保留为最直接的原子知识候选，并考虑补进长期概念雷达的 `Guardrails / Observability` 交叉判断。

### 3. `Connected tools with user-scoped permissions`

- 为什么值得关注：`Lovable` 在 `2026-07-29` 推出 `App user connectors`，并且此前已经把应用接入 `ChatGPT / Claude`。
- 今天的判断：AI app builder 的下一层重点不是“能不能生成页面”，而是“能不能安全接入用户真实数据和外部工具”。
- 建议动作：放入长期平台观察，优先挂在 `Lovable / MCP / AI app builder governance` 交叉处。

### 4. `Design-to-code workspace`

- 为什么值得关注：`Figma Make` 的 `properties panel and annotations` 说明重点已经不是生成首稿，而是围绕生成结果做参数控制、比较和团队协作。
- 今天的判断：更重要的不是“Figma 能不能生成代码”，而是设计与前端正在共享同一个可运行工作台。
- 建议动作：先保留为高优先级概念，适合后续拆成产品 / 工作流判断。

### 5. `Browser-native tooling`

- 为什么值得关注：虽然今天没有浏览器新官方大新闻，但 `chrome-devtools-mcp`、`playwright-mcp`、`browser-use` 这条线继续在 GitHub 热门和工具生态中保持高能见度。
- 今天的判断：它仍是前端 agent 是否能闭环调试页面的关键能力，不应被今天的 voice / cowork 仓库热度稀释。
- 建议动作：继续作为长期能力方向，不因单日涨星新增太多仓库笔记。
