- 为什么值得关注：OpenAI 在 `2026-08-01` 直接用 `price-performance frontier` 描述 GPT-5.6，这不是普通宣传措辞，而是在把模型升级翻译成工程采用理由。

### 2. `Skills + MCP + code review`

- 建议动作：升级为长期判断，优先挂到 `Agent Skill`、`Guardrails`、`Observability` 交叉处。

### 3. `Workflow layer > model catalog`

- 为什么值得关注：`GitHub Models retired` 再次给出硬证据，表明模型目录越来越像底层供给，而不是主要竞争层。
- 今天的判断：这条线已经足够稳定，后续适合持续作为判断框架使用。
- 建议动作：继续保留为长期主线；如果要推进，优先拆成正式原子知识。

### 4. `MCP engineering phase`

- 为什么值得关注：`MCP RC` 与 `GitHub MCP Server next spec` 连续出现，说明接下来比较 MCP 不该只看 server 数量，而要看 `host / SDK / auth / tasks / apps`。
- 今天的判断：MCP 已明显进入工程稳定期，未来更像系统能力层，不再只是连接器热词。
- 建议动作：保留为长期能力方向，必要时补写一条“为什么 MCP 的比较维度已从工具数量切到工程兼容性”的原子知识。

- 今天的判断：这条线会直接影响你如何理解前端 agent、设计 agent 和 app builder 的边界。
- 建议动作：继续挂在 `前端 / 设计协作 / Agent workspace` 交叉处，不急着新增太多单仓库笔记。
