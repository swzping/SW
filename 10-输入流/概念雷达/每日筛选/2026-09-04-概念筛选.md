## 今天值得关注的概念

1. `website-native tool surface`
   - 证据：`ChatGPT & Codex changelog` 把 `Site tools (WebMCP)` 写成正式能力。
   - 判断：网站开始从“被浏览对象”长成“向 agent 暴露工具的执行表面”，这是 `Browser Use` 与 `MCP` 合流的明确信号。
   - 分类：长期能力方向

2. `execution location governance`
   - 证据：Cursor 在 `2026-09-02` 推出 `self-hosted machines`。
   - 判断：agent 企业化落地的重点已从“能不能接仓库”继续上移到“任务在哪台机器执行、由谁控制网络和密钥”。
   - 分类：长期能力方向

3. `model rollout governance`
   - 证据：OpenAI 在 `2026-09-03` 到 `2026-09-04` 的 Astra rollout 文档里把 `Work / Codex allowance`、`separate model controls`、`rolling availability` 写得很清楚。
   - 判断：平台正在把模型上线过程本身产品化，用户以后要管理的不只是模型选择，还包括 rollout、额度和任务类型。
   - 分类：长期能力方向

4. `context boundary governance`
   - 证据：GitHub Copilot `content exclusions` 已 GA。
   - 判断：治理边界已经进入正式产品层，并且和 `execution location`、`default model policy` 开始形成控制面组合。
   - 分类：长期能力方向

5. `skill state runtime`
   - 证据：`SKILL.state` 论文在 `2026-09-02` 更新 v3。
   - 判断：`skill` 正在从 markdown 方法包继续往 runtime architecture 演进，值得持续观察。
   - 分类：长期能力方向
