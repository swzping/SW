## 今天值得关注的概念

### 1. `ChatGPT Work` 不再只是长任务模式，而是在长成统一工作台

- 为什么值得关注：OpenAI 已把 `Work` 绑定到 `文档 / 表格 / Sites / 定时任务`，并且把 `ChatGPT agent` 收回到 Work 叙事里。
- 今天的判断：这条线比“又一个新模型名”更重要，因为它会改变 `ChatGPT / Codex / 交付产物 / 连接应用` 的边界。
- 建议动作：保留为高优先级长期主线，但今天不额外新建长期条目。

### 2. `Review policy as code` 正在变成 coding agent 的默认配置层

- 为什么值得关注：GitHub Copilot code review 已开始读取 `REVIEW.md`、`GEMINI.md`、`CLAUDE.md`，并支持独立 setup steps 与网络限制；Codex 也在强化自定义 code review rules。
- 今天的判断：以后比较 coding agent，不应只看生成能力，而要看 `是否能被团队规范约束、是否能接入现有 review 流程`。
- 建议动作：建议作为原子知识候选保持高优先级。

### 3. `Observability` 已经从调试层长到组织治理层

- 为什么值得关注：`Copilot usage metrics API`、`repository-level metrics`、`impact dashboard` 连续出现，已经不是零散指标。
- 今天的判断：`session visibility + usage metrics + adoption phases` 会一起决定团队如何采购和扩展 agent 工具。
- 建议动作：今天更适合补充主题地图，而不是只记成新闻。

### 4. `AI gateway / routing / compression` 在继续实化

- 为什么值得关注：今天涨得快的 `OmniRoute` 与之前持续出现的 `OpenRouter / gateway / context compression` 是同一长期主线。
- 今天的判断：这条线已经从“省钱技巧”升级为 `多模型、降级、压缩、授权和可观测` 的基础设施组合层。
- 建议动作：先保持在筛选和整理建议，不直接升级某个热门仓库为长期追踪。

### 5. `Design agent workspace` 正在成形

- 为什么值得关注：Figma 一边把 `GPT-5.6` 放进 Make，一边继续强化 `Figma agent skills`，说明设计协作也在走 `模型 + 工作流 + skill` 结构。
- 今天的判断：设计工具的主线不是“更会生成首稿”，而是 `更好接入团队上下文和协作方式`。
- 建议动作：建议保留为主题地图更新候选。
