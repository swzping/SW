# 2026-07-06 概念筛选

日期：2026-07-06
对应日报：[[../../日报/AI圈新闻-2026-07-06|AI圈新闻 - 2026-07-06]]

## 先给结论

今天最该筛出来的，不是“哪个新仓库最火”，而是下面四条已经被官方文档、平台动作、论文和 GitHub 项目反复强化的长期能力方向：

1. `Agent Skill` 正在成为跨平台的通用组织层。
2. `MCP` 正在向 `apps + enterprise authorization + browser access` 扩层。
3. `workflow layer > model catalog` 的判断继续被 GitHub 平台动作强化。
4. `Agent Memory` 的重点正在转向 `审计 / benchmark / state-aware failure`。

## 今天值得关注的概念

### 1. Agent Skill 进入长期主线确认阶段

- 来自信号：
  - OpenAI Developers 持续写 `skills`
  - Figma 在 `2026-07-01` 明确发 `Got Skills?`
  - Anthropic 产品侧也把 `skills` 放进 Claude 生态
- 为什么值得关注：
  - 这说明 `Skill` 已经不是平台私货，而是“把团队上下文、做事方式、限制条件和复盘方法交给 agent”的通用结构。
- 建议动作：
  - 进入长期追踪明确主线，不再只当“可拆的一个概念候选”。
- 判断：
  - 长期能力方向，重要性 `A`。

### 2. MCP 从工具协议继续长向工作流协议

- 来自信号：
  - MCP 官方当前文档已正式拆出 `MCP Apps`
  - `Enterprise-Managed Authorization` 已成为独立扩展页
  - Safari MCP server 继续证明浏览器能力接入正在落地
- 为什么值得关注：
  - 这说明 MCP 的重心不再只是“工具能不能调用”，而是“工具怎样被嵌入 app、怎样授权、怎样进入团队生产流程”。
- 建议动作：
  - 继续保留在长期主线，并把 `MCP Apps`、`企业授权` 作为 `MCP` 下的子判断，而不是单独追热词。
- 判断：
  - 长期能力方向，重要性 `A`。

### 3. Workflow Layer > Model Catalog 继续被平台层验证

- 来自信号：
  - GitHub 在 `2026-07-01` 宣布 `GitHub Models` 将于 `2026-07-30` 退场
  - GitHub 同日补 `auto model selection`
  - `2026-07-02` 再补 `agent session streaming`
- 为什么值得关注：
  - 平台竞争焦点更明确地转向 `任务执行可见性`、`默认策略`、`权限`、`成本` 和 `会话过程`。
- 建议动作：
  - 挂到 `AI Gateway`、`Observability`、`Context Engineering` 的交叉判断里，并同步更新产品雷达里 `GitHub Copilot / Copilot Cloud Agent` 的判断。
- 判断：
  - 长期能力方向，重要性 `A-`。

### 4. Memory Evals / Memory Audit 比“记住更多”更重要

- 来自信号：
  - `A-TMA`
  - `MemoryArena`
  - `EvoMemBench`
- 为什么值得关注：
  - 长时记忆的问题正在被拆成更具体的失败类型与 benchmark 维度。
- 建议动作：
  - 先作为 `Agent Memory` 的新判断写进候选，不急着拆很多独立笔记。
- 判断：
  - 长期能力方向，重要性 `A-`。

### 5. Loop Engineering 开始从文章走向工具化

- 来自信号：
  - `openai/codex-plugin-cc`、`page-agent`、`chrome-devtools-mcp` 说明“技能 + 浏览器 + 委派”已经在开源层进入可执行形态
  - 开源叙事从“讲概念”转向“给出可调用工具和闭环”
- 为什么值得关注：
  - 这说明 loop 不再只是方法论口号，正在形成可执行工作流。
- 建议动作：
  - 继续挂在 `Loop Engineering` 主题下观察，不单独追仓库热度。
- 判断：
  - 长期能力方向，重要性 `B+`。
