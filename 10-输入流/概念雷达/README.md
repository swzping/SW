# 概念雷达

这里保存从日报、网络资料和对话中提炼出的概念候选。

概念雷达回答的问题是：

- 哪些 AI/Agent/LLM 概念值得我持续理解？
- 哪些词不是一次性新闻，而是会影响后续判断？
- 哪些概念应该拆成原子知识，甚至升级成主题地图？

## 文件规划

| 目录 | 用途 |
| --- | --- |
| `每日筛选/` | 每天从日报中筛出值得关注的概念，文件名为 `YYYY-MM-DD-概念筛选.md`。 |
| `长期追踪/` | 长期维护的概念、模型、平台和工具观察清单。 |

## 当前重点

建议先从这三个概念开始：

- MCP
- Loop Engineering
- Agent Memory

## 处理方式

每日筛选不是最终知识。处理时只做一件事：挑出值得长期跟踪的词，拆成 `20-原子知识/概念/`。

如果同一个概念反复出现，并且影响多个判断，再升级到 `30-主题地图/`。
