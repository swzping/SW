# 社媒收藏

这里保存来自抖音、B 站、小红书、公众号、X、YouTube 等平台的收藏内容。

社媒收藏先作为输入流处理，不直接进入原子知识。只有当内容能形成判断、方法、案例或长期问题时，才升级到 `20-原子知识/` 或 `30-主题地图/`。

## 使用方式

你只需要提供以下任意一种材料：

- 分享链接。
- 视频标题和作者。
- 截图。
- 复制出来的文案或字幕。
- 通过 Computer Use 从收藏页采集到的条目。

整理助手负责：

1. 识别主题和价值。
2. 生成摘要、核心观点、可执行启发和待验证点。
3. 判断是否值得升级为原子知识。
4. 给出下一步建议，等待确认后再写入正式知识区。

## 放置规则

- 未整理材料：放到 `待处理/`。
- 抖音 AI 收藏批次：放到 `抖音AI收藏/`。
- 单条内容很重要但证据不足：保留在社媒收藏，不进入原始资料。
- 官方文档、论文、项目 README 等可引用证据：另存到 `10-输入流/原始资料/`。

## 处理节奏

- 日常：你说“整理这批抖音收藏”，整理助手按模板处理。
- 每天 18:00：每日知识推进会读取最近社媒收藏批次，挑出值得升级、补证据或继续观察的候选。
- 每周：从本周社媒收藏中挑 3-5 条值得沉淀的内容，升级为原子知识或主题地图更新。
- 以后：如果采集链路稳定，再做脚本或 MCP；当前先以半自动工作流为主。
