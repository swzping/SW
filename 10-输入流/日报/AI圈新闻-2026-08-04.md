## GitHub 热门项目观察

### Star 增长最快

以下更适合当作“今天的增长样本”，不自动升级为长期追踪对象：

1. [`microsoft/skill-recorder`](https://github.com/microsoft/skill-recorder)
   - 项目归类：`skill`
   - 解决问题：把屏幕上的真实操作录成 `intent + ordered steps`，再反向生成可复用 skill 或 automation。
   - 适合行业：前端研发、通用软件工程、教育研究
   - 适合场景：工作流编排、文档整理、异步任务执行

2. [`perplexityai/numbat`](https://github.com/perplexityai/numbat)
   - 项目归类：`evals / observability 工具`
   - 解决问题：提供 endpoint 侧 agent 活动可见性、预动作阻断和取证重建。
   - 适合行业：通用软件工程、企业内控 / 知识管理、教育研究
   - 适合场景：评测 / 观测、安全授权、异步任务执行

3. [`mikehasa/agentacct`](https://github.com/mikehasa/agentacct)
   - 项目归类：`evals / observability 工具`
   - 解决问题：拆解 coding agent 每个任务的步骤、文件改动、测试、耗时与 token 成本。
   - 适合行业：前端研发、通用软件工程、企业内控 / 知识管理
   - 适合场景：评测 / 观测、代码审查、异步任务执行

4. [`VictorTaelin/OptMem`](https://github.com/VictorTaelin/OptMem)
   - 项目归类：`memory 工具`
   - 解决问题：提供低提示开销的长期记忆接入思路，强调 agent 记忆的轻量工程化。
   - 适合行业：教育研究、企业内控 / 知识管理、垂直行业工作台
   - 适合场景：长期记忆、知识检索 / RAG、工作流编排

5. [`F-loat/panerelay`](https://github.com/F-loat/panerelay)
   - 项目归类：`browser / MCP 工具`
   - 解决问题：让 agent 复用你已经在使用的 Chrome / Edge，而不是另起浏览器容器。
   - 适合行业：前端研发、通用软件工程、运营投放
   - 适合场景：浏览器自动化、前端调试、异步任务执行
