# AI圈新闻 - 2026-07-23

日期：2026-07-23

## 今日摘要

截至 `2026-07-23` 上午扫描，今天最重要的不是又一个更大的模型名，而是三条工作流层信号继续加厚：

1. `OpenAI` 正把 `ChatGPT Work + Codex + 可交付产物` 收进统一工作入口。`ChatGPT Work and Codex`、`Creating and managing ChatGPT Sites`、`Creating and editing documents, spreadsheets, and presentations with ChatGPT Work` 说明 Work 已经不只是“长任务模式”，而是在向 `文档 / 表格 / 报告 / Sites / 定时任务` 的 agent 工作台靠拢。
2. `GitHub Copilot` 的重点继续从模型目录迁向 `治理 / 度量 / review 配置层`。`New Copilot usage metrics impact dashboard`、`Gemini 3.6 Flash is now available in GitHub Copilot`、`Copilot code review: Customization and configurability improvements` 一起说明：平台开始默认要求 `模型可切换 + 使用可度量 + review 可配置`。
3. `Vercel / Figma` 继续把前端与设计工作流往 agent workspace 形态推进。`Introducing the new Vercel Agent`、`AI SDK 7`、`GPT-5.6 is now available in Figma Make`、`Got skills? Make the Figma agent a better collaborator` 都指向同一件事：真正影响你前端开发和 Agent 工作流的，是 `runtime context / approvals / skills / telemetry / 可交付产物` 的组合层。

今天的覆盖来源以 OpenAI Help Center / Developers、GitHub Changelog、Vercel Blog、Figma Blog、GitHub Trending / Search 为主。今天没有发现压过这些工作流变化的新旗舰模型发布，因此日报重点放在 `工作台入口 + metrics / observability + review policy + design / frontend agent stack`。

## 热点新闻 Top 10

1. `ChatGPT Work` 正式成为 OpenAI 的长任务入口
   - 来源：OpenAI Help Center `ChatGPT Work and Codex`。
   - 影响：OpenAI 明确把 `Chat / Work / Codex` 分层，Work 面向长任务与交付物，Codex继续专注软件开发。这会改变你以后怎么理解 ChatGPT 与 Codex 的边界，而不是只盯模型名。

2. `ChatGPT agent` 被 `Work` 替代
   - 来源：OpenAI Help Center `ChatGPT agent`。
   - 影响：这说明 OpenAI 正把 agent 能力从“单独模式”收进更稳定的工作入口，长期更值得跟踪的是 `Work` 能否成为通用 agent 工作台。

3. `ChatGPT Work` 已开始覆盖 `Sites / 文档 / 表格 / 报告`
   - 来源：OpenAI Help Center `Creating and managing ChatGPT Sites`、`Creating and editing documents, spreadsheets, and presentations with ChatGPT Work`。
   - 影响：对内容生产、研究整理、内部工作台和前端 demo 产出都有直接意义，尤其值得观察它和 Codex 的分工是否继续清晰。

4. GitHub 发布 `New Copilot usage metrics impact dashboard`
   - 来源：GitHub Changelog，`2026-07-22`。
   - 影响：Copilot 的重点继续从“谁在用”升级到“用了多深、进入哪个 adoption phase”，说明 observability 已经进入组织治理层。

5. `Gemini 3.6 Flash` 开始进入 GitHub Copilot
   - 来源：GitHub Changelog，`2026-07-21`。
   - 影响：这再次证明 GitHub 的重点不是自有模型，而是 `多模型选择 + 统一工作流 + 可计费治理`。

6. `Copilot code review` 的配置与控制能力继续增强
   - 来源：GitHub Changelog，`2026-07-17`。
   - 影响：现在它会读 `REVIEW.md`、`GEMINI.md`、`CLAUDE.md`，也支持独立 setup steps 与更细的网络控制。`review policy as code` 正在成为默认工程层。

7. `Vercel Agent` 在 `2026-07-21` 扩展为 Dashboard 内的一等入口
   - 来源：Vercel Blog `Introducing the new Vercel Agent`。
   - 影响：这不是普通“AI 助手”更新，而是把 `生产调查 / 审批 / 回滚 / 修复 PR` 直接做进部署平台，对前端团队最有参考价值。

8. `AI SDK 7` 继续巩固 TypeScript Agent 基建层
   - 来源：Vercel Blog `AI SDK 7 is now available`。
   - 影响：`reasoning control`、`tools context`、`runtime context`、`tool approvals`、`telemetry`、`skills support` 被拉进一个统一 SDK，说明前端 Agent 基建正在成熟。

9. `GPT-5.6` 已进入 Figma Make
   - 来源：Figma Blog，`2026-07-09`。
   - 影响：设计到代码工作流正在更明确地依赖模型层，但真正关键的是 Figma 如何把模型嵌进 `Make + agent + skills + MCP` 的协作层。

10. `Figma agent` 的 `skills` 继续成为官方主线
   - 来源：Figma Blog `Got skills? Make the Figma agent a better collaborator`，`2026-07-01`。
   - 影响：Skill 已经不是 coding agent 私有概念，而是正式跨到 design / prototyping / design-to-code 协作层。

## 模型 / 论文 / API

- `ChatGPT Work`
  - 今天最值得跟踪的不是模型参数，而是 OpenAI 把 Work 明确成 `长任务 + 可交付产物 + Sites + 定时任务` 入口。

- `Gemini 3.6 Flash in GitHub Copilot`
  - 这说明 coding agent 平台的竞争点进一步转向 `多模型选择与统一计费 / 治理层`。

- `AI SDK 7`
  - 对前端与 TypeScript 团队最有现实意义，因为它把 `reasoning / tools / approvals / telemetry / skills` 收成同一层 API。

- `GPT-5.6 in Figma Make`
  - 值得继续观察它是否会推动 `design-to-code` 从“生成首稿”走向“循环迭代 + 多人协作 + skill 化”。

## 值得跟踪的问题

1. `ChatGPT Work` 会不会逐步吞掉原本独立的 agent mode，成为 OpenAI 的默认通用 agent 工作台？
2. `review policy as code` 会不会在 Codex、Copilot、Claude Code 三边同时变成默认能力？
3. `usage metrics dashboard + adoption phases` 会不会让 agent 工具采购标准从“能不能用”改成“能不能量化组织收益”？
4. `AI gateway / routing / context compression` 会不会成为个人和小团队做 Agent 工作流的基础设施层？
5. 设计工具里的 `skills + MCP + model choice` 会不会比单次设计生成更快形成稳定工作流标准？
