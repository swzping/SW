# AI圈新闻 - 2026-08-13

日期：2026-08-13
时区：Asia/Shanghai

## 今日摘要

今天最值得注意的新变化，不是又多了一个热仓库，而是 `模型默认层开始直接进入 agent 工作台治理`。OpenAI 帮助文档当前已明确：`gpt-5.4` 与 `gpt-5.4-mini` 将在 `2026-08-31` 从 ChatGPT 登录的 Codex 中退役，默认替代为 `gpt-5.6-terra` 与 `gpt-5.6-luna`。这说明模型切换已经不只是 API 版本变化，而是在直接影响 `custom agents`、`scheduled tasks`、`workspace defaults` 这一层。

除此之外，过去几天形成的四条主线今天没有被推翻，反而继续稳固：`统一 AI 工作台`、`Skill 进入 runtime / review / app workspace`、`browser-native tooling`、`AI app builder 程序化`。GitHub 项目样本层面，今天更值得看的仍是 `memory`、`observability`、`browser / MCP`、`skill` 这几类长期能力方向，而不是单日涨星。

## 热点新闻 Top 10

1. `OpenAI / Codex`：`gpt-5.4` 与 `gpt-5.4-mini` 将在 `2026-08-31` 从 ChatGPT 登录的 Codex 中退役。
   - 影响：默认替代模型是 `gpt-5.6-terra` 与 `gpt-5.6-luna`。
   - 判断：这说明模型生命周期管理已经进入 `agent workspace` 默认层，会影响自定义 agent、计划任务和默认执行配置。

2. `OpenAI`：`GPT-5.6` 继续作为 ChatGPT、Codex、API 的统一默认能力层。
   - 影响：更该观察它如何改变默认工作流、异步任务和工具调用稳定性，而不只是看榜单。

3. `OpenAI`：`ChatGPT for your most ambitious work` 与 `Atlas -> ChatGPT for browser-based agentic work` 仍在补强统一工作台叙事。
   - 影响：`ChatGPT + Codex + browser work + long-running tasks` 越来越像同一入口，而不是分散工具。

4. `OpenAI Developers`：`Skills in the Agents SDK` 继续提供官方 runtime 级证据。
   - 影响：`Skill` 已经不只是提示模板，而是方法资产和执行组织层。

5. `GitHub Copilot`：`Agent skills + MCP in code review` 仍是重要横向证据。
   - 影响：`Skill` 已进入 review workflow，而不是只服务代码生成。

6. `MCP`：`2026-07-28 Release Candidate` 继续说明协议进入工程稳定期。
   - 影响：接下来更该看 `host / SDK / auth / app / task` 兼容，而不是只比 server 数量。

7. `WebKit`：`Safari MCP server` 继续强化浏览器原生能力接入 agent。
   - 影响：前端调试和浏览器自动化正在成为主执行层的一部分。

8. `Vercel`：`v0 API` 继续说明 AI app builder 在进入程序化能力层。
   - 影响：builder 已经可被外部 workflow 和异步任务编排，而不只是聊天出页面。

9. `Figma`：`local code for Figma Make` 与 `Figma agent skills` 继续补强 design workspace 路线。
   - 影响：设计协作也在出现 `local code + skills + context` 组合层。

10. `Replit`：`Agent Skills` 文档仍是 builder 平台吸收 skill layer 的代表证据。
   - 影响：`builder + skill + runtime` 正在跨平台收敛。
