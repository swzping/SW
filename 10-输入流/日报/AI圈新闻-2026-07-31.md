## 热点新闻 Top 10

1. `GitHub Models is now retired`
   - 来源：GitHub Changelog，`2026-07-30`
   - 影响：这不是普通下线通知，它进一步支持 `workflow layer > model catalog`。以后比较平台，更该看 `runtime / routing / review / governance / observability`，而不是模型目录。

2. `Figma Make: properties panel and annotations`
   - 来源：Figma Blog，`2026-07-30`
   - 影响：设计生成工具正在补 `参数控制 + 团队批注`，重点已经不是“能不能生成”，而是“能不能协作迭代并接近真实交付”。

3. `App user connectors let your users connect their own tools`
   - 来源：Lovable Blog，`2026-07-29`
   - 影响：AI app builder 正在进入 `user-scoped connectors + auth boundary` 阶段，这比继续追单个 UI 生成能力更接近真实 agent 落地。

4. `The 2026-07-28 MCP Specification Release Candidate`
   - 来源：Model Context Protocol Blog，`2026-07-28`
   - 影响：`stateless core`、`Tasks extension`、`MCP Apps`、`authorization hardening`、`formal deprecation policy` 被收进同一版升级路线，MCP 正进入更稳定的工程期。

5. `GitHub MCP Server supports the next MCP specification`
   - 来源：GitHub Changelog，`2026-07-25`
   - 影响：MCP 的竞争点继续从“工具目录”转向 `host compatibility / workflow compatibility / SDK migration cost`。

6. `Agent automation controls in GitHub Issues in public preview`
   - 来源：GitHub Changelog，`2026-07-24`
   - 影响：`automation boundary` 已经被显式产品化，之后比较 coding agent 不能只看代码质量，还要看接管、限制、审计和回退。

7. `Introducing Cursor Router`
   - 来源：Cursor Blog，`2026-07-22`
   - 影响：Router 已跨 desktop / web / iOS / CLI / SDK 产品化，说明 coding agent 平台的核心能力正在转向 `模型路由 + 成本控制 + 任务分层`。

8. `Introducing the new Vercel Agent`
   - 来源：Vercel Blog，`2026-07-21`
   - 影响：`dashboard + approvals + telemetry + rollback / PR handoff` 被收进同一工作流，前端团队需要开始把 agent 看成上线系统的一部分。

9. `Custom Code Review rules for Codex`
   - 来源：OpenAI Developers Blog，`2026-07-20`
   - 影响：`review policy as code` 已进入 Codex 默认工作流层，对团队规范、审查质量和自动化边界尤其关键。

10. `Your Lovable app now works inside ChatGPT and Claude`
   - 来源：Lovable Blog，`2026-07-15`
   - 影响：这说明 AI app builder 正在向 `app becomes tool for other agents` 方向推进，而不只是独立网页生成器。

## 模型 / 论文 / API

- `GitHub Models retired`
  - 今天更值得记住的不是它“下线了”，而是平台对外明说：模型目录不再是主要差异化层。

- `Codex review rules + skills`
  - 这组 OpenAI 官方材料说明，后续更值得关注的是 `review policy`、`skill 资产`、`团队规范` 如何进入默认工作流。

- `Figma Make + annotations + properties panel`
  - 设计工具继续朝 `可运行工作台` 收敛，后续值得重点看 `local code / repo sync / review handoff`。

- `论文线说明`
  - 今天没有发现优先级高于 `workflow layer / governance / connected tools / design workspace` 的新论文；arXiv 覆盖更多仍服务于 `memory / context engineering / evals` 的长期背景判断。

## 值得跟踪的问题

1. `workflow layer > model catalog` 会不会在更多平台上从隐性判断变成显性产品路线？
2. `connected tools + user-scoped permissions` 会不会成为 AI app builder 的标准底座？
3. `review policy + automation boundary` 会不会在 Codex、Copilot、Cursor、Lovable 这些不同平台之间继续收敛？
4. `design-to-code workspace` 会不会比“从设计直接导出代码”更重要，因为它把协作、验证和迭代收到了同一界面？
5. `browser-native tooling` 会不会在下个阶段跟 `MCP Apps / Tasks / review loop` 更深地捆在一起？
