## 值得跟踪的问题

1. `managed plugin / app surface` 会不会成为统一工作台的默认扩展层，而不是单独插件市场？
2. `browser-based agent work` 会不会在前端调试、设计验证和资料整理里比 IDE 更快成为日常入口？
3. `secure connector layer` 会不会收敛成 `connector product + auth policy + gateway` 的统一控制面？
4. `team chat as agent work surface` 会不会先在企业组织中跑赢 IDE 内嵌入口？
5. `repo-level agent workspace` 会不会成为 IDE 与云端 agent 的共同默认壳层？
