# AI圈新闻 - 2026-08-10

日期：2026-08-10

## 今日摘要

今天更值得记录的不是单一模型新闻，而是 `official skill runtime`、`AI app builder API 化`、`browser / code review 工程层`、`design agent 协作层`、`agent memory / observability` 这五条线在近几天继续共振。

- OpenAI Developers 的 `Skills in the Agents SDK` 继续强化一个判断：`Skill` 已不只是 prompt 包，而是在进入官方 agent runtime 组织层。
- GitHub 在 `2026-08-07` 宣布 `Copilot code review: Agent skills and MCP now generally available`，说明 `Skill + MCP` 已从代码生成扩到审查流。
- Vercel 的 `Introducing the new v0 API` 继续把 `v0` 从聊天式 builder 推向可编排的产品能力层。
- Figma 本周两条连续官方更新 `Introducing local code for Figma Make` 与 `Got skills? Make the Figma agent a better collaborator`，说明 design agent 正从“生成首稿”走向 `代码上下文 + skills + 协作`。
- GitHub 热门项目今天更值得看的，是 `browser tooling`、`memory layer`、`evals / observability`、`skill pack` 的稳定聚集，而不是单个仓库名。

## GitHub 热门项目观察

### Star 增长最快

1. `qm`
   - 仓库：<https://github.com/yc-software/qm>
   - 项目归类：`coding agent`
   - 解决问题：把多人协作式 agent harness 做成工作台，强调任务编排和协作执行。
   - 适合行业：`通用软件工程`、`企业内控/知识管理`
   - 适合场景：`工作流编排`、`异步任务执行`
   - 判断：它更像 `agent workbench` 样本，值得看工作台层，不宜只看涨星。

2. `better-harness`
   - 仓库：<https://github.com/QoderAI/better-harness>
   - 项目归类：`evals / observability 工具`
   - 解决问题：把项目和 session 证据转成 loop-level 洞察、改进建议和可验证下一步。
   - 适合行业：`前端研发`、`通用软件工程`
   - 适合场景：`评测/观测`、`代码审查`、`异步任务执行`
   - 判断：代表 `harness engineering + loop engineering`，不是普通提示包。

3. `open-kimi-ppt-skill`
   - 仓库：<https://github.com/Binaryify/open-kimi-ppt-skill>
   - 项目归类：`skill`
   - 解决问题：把 PPT 生成与本地编辑器组合成可调用的 skill。
   - 适合行业：`内容生产`、`教育研究`、`运营投放`
   - 适合场景：`文档整理`、`异步任务执行`
   - 判断：说明 `skill -> 可交付物工作流` 正在增强。

4. `SimpleEnglish`
   - 仓库：<https://github.com/AminBlg/SimpleEnglish>
   - 项目归类：`skill`
   - 解决问题：把技术写作规范封装成 agent skill，降低文档输出偏差。
   - 适合行业：`通用软件工程`、`教育研究`、`企业内控/知识管理`
   - 适合场景：`文档整理`、`工作流编排`
   - 判断：更像 `组织写作规范 skill` 样本。

5. `agentacct`
   - 仓库：<https://github.com/mikehasa/agentacct>
   - 项目归类：`evals / observability 工具`
   - 解决问题：把 coding agent 的任务步骤、工具使用、文件变更、测试和 token 成本做成本地仪表板。
   - 适合行业：`前端研发`、`通用软件工程`、`企业内控/知识管理`
   - 适合场景：`评测/观测`、`代码审查`、`异步任务执行`
   - 判断：说明 `local-first agent observability` 正在形成明确子赛道。
