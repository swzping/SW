# 原始资料

这里只保存重要证据，不作为日常入口。

原始资料尽量不改写。它的作用是保留以后会引用的来源，方便回溯证据。

## 什么时候放这里

- 重要官方文档，例如 MCP 官方文档、OpenAI Agent Guide、Anthropic 工程文章。
- 重要论文，例如 memory、context engineering、agent eval 相关论文。
- 重要项目文档，例如 claude-mem、Hermes Agent、LangGraph。
- 以后写判断时一定会引用的来源。

## 什么时候不要放这里

- 普通新闻链接。
- 随手看到但还没有判断的文章。
- 你的临时想法或问题。
- 系统自动生成的日报和概念雷达。

这些内容先放到 `00-入口/今日工作台.md`、`10-输入流/日报/` 或 `10-输入流/概念雷达/`。

## 原则

原始资料不是收藏夹。只有未来会被引用、验证或复盘的材料，才值得进入这里。
