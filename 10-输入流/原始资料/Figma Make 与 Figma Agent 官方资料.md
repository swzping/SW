## 为什么收藏

这组资料能为 `AI 设计工作流正在从线性流程转向循环生成与整合` 提供一手证据。它们说明 Figma 正在把设计 agent、skills、外部上下文连接、真实数据预览和代码可见性收进同一个协作工作流，而不只是做一次性 UI 生成。

## 中文摘要

- Figma Make 强调从自然语言到可运行 app，并支持继续提示、可视化编辑、查看/修改导出代码和接入真实数据。
- Figma agent 的 skills 不是孤立提示词，而是可复用工作流，可在团队中共享，并和 MCP connectors 结合读取 Slack、Notion、Asana 等上下文。
- 这说明设计工作流的竞争点正在从“生成首稿”转向“循环迭代、上下文协作和工作流接入”。
