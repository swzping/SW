## 为什么收藏

这份资料用于验证社媒条目 `Codex + Paperclip 打造一人公司` 的原始来源。真正值得保留的，不是“一人公司”的短视频表达，而是 Paperclip 是否确实在做一个面向多 agent 的组织层 / 控制面产品。

## 关键内容中文摘要

- 官网明确把自己定义为：`The app people use to manage AI agents for work`。
- GitHub 仓库描述是：`The open-source app everyone uses to manage agents at work`。
- README 明确把定位写成 `Open-source orchestration for teams of AI agents`。
- 项目强调的核心能力包括：org chart、goals、ticket system、heartbeat、budget control、governance、activity tracing、plugins、multi-company isolation。
- README 还明确列出了兼容对象，包括 `OpenClaw`、`Claude Code`、`Codex`、`Cursor`、`Bash` 和 `HTTP bots`。

## 对当前知识库的意义

Paperclip 可以作为 `Agent 组织层 / command center` 的正式样本进入知识区。它说明 Agent 工程不只需要模型、工具和协议，还会长出更高一层的任务系统、预算系统、治理系统和组织结构。
